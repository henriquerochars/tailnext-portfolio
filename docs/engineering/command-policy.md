# Advisory command policy

Status: Live
Owner: [Issue #17](https://github.com/henriquerochars/tailnext-portfolio/issues/17)
Source: Adapted from manager-for-brokers df614a00fbc2377f1ce7250d993a4ce0d63230f5; exact candidate execution evidence belongs in the implementation PR.

The offline classifier accepts argv, not shell text. Exact read-only vectors are advisory candidates; all other actions prompt, destructive reset/root deletion deny. Wrapper/shell commands require review. No recommendation grants execution permission.

Codex rules are restrictive escalation overlays, not a shell parser or sandbox. Adapters are uninstalled candidates with synthetic tests. User/session authorization and native controls remain authoritative. No hooks or host/global settings are modified.
